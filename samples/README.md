# Sample Test Scenarios

This directory contains sample files for testing the Xray Test Automation tool.

## Files

- `sample_test_scenarios.py` - Script to generate a sample Word document with test scenarios
- `sample_test_scenarios.docx` - Sample Word document (generated by the script above)

## Generating Sample Document

To create the sample Word document:

1. Install dependencies:
   ```bash
   pip install python-docx
   ```

2. Run the generation script:
   ```bash
   python samples/sample_test_scenarios.py
   ```

This will create `sample_test_scenarios.docx` with 8 sample test scenarios for an Asset Management system.

## Document Format

The generated document contains a table with the following columns:
- **Scenario ID**: Unique identifier (e.g., AM-001, AM-002)
- **Description**: Brief description of the test scenario
- **Preconditions**: Prerequisites that must be met before executing the test
- **Expected Results**: What should happen when the test is executed successfully

## Usage with Main Script

Once generated, you can use this sample document to test the automation:

```bash
# Using the sample document
python -m src.main -f ./samples/sample_test_scenarios.docx --dry-run

# Or set it in your .env file
TEST_DOCUMENT_PATH=./samples/sample_test_scenarios.docx
```
